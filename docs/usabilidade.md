# Teste de facilidade de uso (roteiro de tarefas)

**Como aplicar (10 min, 1 a 3 pessoas, de preferência MEI ou conhecido de MEI):** rode `python src/sistema.py`, entregue o roteiro abaixo sem explicar o sistema, cronometre cada tarefa e anote dificuldades. Não colete nome nem dados pessoais (use "Usuário 1", "Usuário 2").

| # | Tarefa | Resposta certa | Tempo (s) | Concluiu? (S/N) | Dificuldade observada |
|---|--------|----------------|-----------|-----------------|-----------------------|
| 1 | Descobrir o limite de faturamento anual do MEI | M1 | | | |
| 2 | Escolher um tema pelo `menu` e ler um assunto | qualquer | | | |
| 3 | Perguntar se o cliente pode devolver compra online | C3 | | | |
| 4 | Digitar uma pergunta sem resposta na base e entender o aviso | desconhecida | | | |
| 5 | Seguir um "Veja também" até outro tema | navegou | | | |
| 6 | Dizer qual era a fonte da resposta da tarefa 1 | cita a fonte | | | |

Pergunta final (nota 1 a 5): "O quão fácil foi usar?" e "A resposta ficou clara?"

## Indicadores a calcular
- Taxa de conclusão = tarefas concluídas / tarefas totais
- Tempo médio por tarefa = média dos tempos
- Nota média de facilidade
